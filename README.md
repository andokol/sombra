# Sombra's Night Arcade

A gamified Spanish course for English-speaking beginners, hosted by a black kitten named Sombra.
Built for one 11-year-old, but anyone is welcome to play.

**Play:** https://andokol.github.io/sombra/

- 1,497 questions across 16 worlds, 10 exercise formats
- XP, ranks, streaks, combos, crowns, badges, hats for the cat
- Spanish audio through the browser's own speech voice
- Progress is saved in the browser; add it to your Home Screen and play from there
- Backup and restore your progress as a file or a code

Static site, no build step: `index.html` plus `questions.js`.
